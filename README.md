# Premium Auto Zimbabwe

A cinematic, ultra-premium automotive showroom demo for Zimbabwean vehicle dealerships.

- Luxury editorial automotive aesthetic
- Cinematic 4-vehicle hero slider
- Premium inventory discovery
- Vehicle detail pages
- USD-first Zimbabwean buying journey
- WhatsApp-first sales conversion
- Mobile-first and performance-conscious

This is a reusable master demo intended to be customized for individual dealerships.
